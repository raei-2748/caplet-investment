Status labels (brief section 3): **VP** = VERIFIED-PRIMARY (I read it on the primary page on 2026-09-27; URL in
section 6); **VRF** = VERIFIED-REPO-FILE; **SNIP** = SNIPPET-UNVERIFIED; **ASM** = ASSUMPTION; **PARA** =
PARAPHRASE-UNVERIFIED; **INT** = INTERPRETATION (my reading, never a fact); **DER** = derived arithmetic (script in
Appendix A; its inputs carry their own labels). Every "hypothesis" below is a guess.

Terms used (defined once):
- **Funded ratio**: money available divided by today's market price of the promised payments.
- **Required return**: the smallest yearly return that still meets a goal.
- **Hurdle**: the return an alternative would have given without risk. A risky choice has to beat it to be worth taking.
- **Certainty equivalent**: the sure amount a person would accept in place of a risky one.
- **Forward rate**: the interest rate that today's Treasury curve locks in for a future period.
- **Affordable loss**: an entrepreneur's rule of deciding first how much you can afford to lose, instead of starting
  from how much you hope to gain.
- **Sleeve**: the part of the portfolio outside the Treasury ladder; it holds the risk.

## Appendix A: script used (scratch; formulas so D3 can reproduce)

PV27  = sum(50000*DF(y) for y in 2033..2042)/DF(2027)            -> 292,264
dep28 = 150000*DF(2028)/DF(2027)                                  -> 143,230
funded = (300000 + dep28)/PV27                                    -> 151.7%
break-even r: 300000(1+r)^6 + 150000(1+r)^5 = sum_{k=0..9} 50000/(1+r)^k  -> 1.05%
locked surplus 2033 = (300000-PV27)*DF(2027)/DF(2033) + 150000*DF(2028)/DF(2033) -> 203,998

## What this teaches
A professional adviser does not start with "what should we buy?". The first step is filling in a grid about the
client: what return each goal *needs*, how much risk the person *wants* and how much they *can afford*, when each
dollar is needed, and what is special about them. For Laura the grid gives answers a generic plan misses.
- Her promise needs almost no return.
- Her ability to take risk switches on only when her second deposit arrives.
- The risk she takes buys little this year, so it has to be justified against the sure thing she could have instead.
- Her own entrepreneur's rule ("decide what you can afford to lose") is a better translation of "thoughtful risks"
  than any risk label.

The other lesson is honesty about gaps. Where the profile is silent, a good adviser says what was assumed and what
changes if that assumption is wrong.
