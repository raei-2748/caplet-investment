## Method
1. Loaded `phase_B/quotes_raw.json` and `phase_D/D13_mechanical_check.json`. Classified the speaker of each quote from its text and context. Quotes by Laura herself (100) went to D13a; everything else (171) is here.
2. Script `research/insight_v1/scripts/D13b_other_quotes_context.py` re-fetched every page with the fixed helper and saved a 350-character window around each quote (`phase_D/_work/D13b_contexts.json`). Every window was read to check speaker, context and trimming. Named speakers and dates were confirmed on the page (e.g. Vittorelli, Balchunas, McCormick, Hahn, Owens, all paper authors).
3. Re-tried all 21 non-VERBATIM quotes, using Wharton REST API, legislation.gov.uk, Europe PMC, eCFR, Cornell LII, the direct Box PDF and repo files.
4. Script `research/insight_v1/scripts/D13b_build_outputs.py` records the judgements and writes the JSON and the table below.

Status meaning here: VERIFIED-PRIMARY = the exact wording was read on the primary page or official repo file on 2026-09-27. For repo files this equals VERIFIED-REPO-FILE. "Status note" says where attribution is weaker than the wording.

## What this teaches
- A quote can be word-for-word correct and still be misattributed. The most common trap here was not wrong wording. It was a writer's paraphrase (Balchunas, Nichole Jordan) or a reporter's sentence being read as the person's own voice. Before you write "X said", check whether the words sit inside quotation marks next to X's name.
- "Not found" by a script often means "hidden", not "made up". Five Wharton quotes live in hidden or retired page sections that only the site's own API shows. Three abstracts sat behind publisher blocks but were open in Europe PMC. Two failed only because a PDF split a word across a line. Try the official back door before you call a quote wrong.
- Old rules can survive on live pages. The "one sector per team member" rule was genuine Wharton text in past seasons. That is exactly why it kept coming back as a claim for 2026-27, when it is no longer a rule. Always check the season of the page.
- An unnamed pull quote is the case's voice, not the client's, until a source proves otherwise. Writing "the case profile highlights..." costs nothing; putting words in Laura's mouth could cost credibility with the readers who know her.
