# Team Caplet: Google Drive export

Plain-file copies of Team Caplet's Google Drive documents for the Wharton Global High School Investment Competition 2026-27, so they can be read on GitHub.

- **Export date:** 2026-10-14 (read-only export; nothing on Google was edited, commented on or shared).
- **Format:** one Markdown file per Doc (every tab under its own heading; the IPS Report has one file per tab), one CSV per Sheet tab (values as displayed).
- **Not live:** the Google files remain the source of truth. These copies go stale as soon as the team edits the originals.
- **Privacy (this repo is public):** student names are cut to first name + surname initial; emails, year levels, WInS usernames and passwords are removed and marked `[personal details removed]` or `[removed]`. Laura Gao (the competition's case client) and public figures are kept. Images are shown as `[image]` placeholders.
- **Comments:** open comment threads are included at the end of a file where the doc had any (IPS Report Version 5 and V4 tabs; 2025 Knox Wharton). Rules, Notes & Discussions, Team List, Final Report, Strategy Notes, Client Portrait and Resource had no comments.
