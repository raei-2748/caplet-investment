# The Noticeboard (real work, not fiction)

> Room card: `keel/OFFICE.md`. This folder was called the "Keel project office" until 23 Oct 2026; the path is
> unchanged. Nora's home room.

Team Keel runs Caplet's competition work like a professional project team, and works without being asked. The
people in the story are fiction; **the tasks, dates, risks and decisions in this folder are real** and are about
Caplet's own deliverables. Keel names here mean the AI desk that owns the job (see `keel/README.md`); Caplet roles
mean a real student. Keel proposes; Caplet decides, rewrites, submits; only Ray trades.

| File | What it is | Updated by |
|---|---|---|
| `LOOP.md` | The operating loop every Keel session runs: read the board, pick the top task, do it, update, propose | - |
| `BOARD.md` | Task board: Doing / Ready / Waiting on Caplet / Proposed / Done, with owner, due date and priority | every loop run |
| `ROADMAP.md` | Milestones and gates to each deadline (Sydney time) | Nora, weekly |
| `PREMORTEMS.md` | "It's the day after the deadline and we failed. Why?" One per deliverable, before it is drafted | Nora + Kai |
| `RISKS.md` | Risk register: likelihood x impact, owner, early warning, mitigation | weekly, and on any trigger |
| `DECISIONS.md` | Queue of decisions waiting for a Caplet vote (options, memo, vote date). Votes taken go to `caplet/decisions/LOG.md` | every loop run |
| `RETROS.md` | Retrospective after each deliverable: plan vs actual, keep / stop / start, one process change | after each deadline |
| `STANDUP.md` | Five-line stand-up written at the end of every loop run (newest first) | every loop run |
| `ROUTINES.md` | The scheduled routines: the ten existing Mac checks and the proposed cloud routines | - |

**Methods used.** Kanban with a work-in-progress limit (3 in Doing, 1 per run); priority = impact x urgency;
definition of done on every task; pre-mortem (Klein) before each deliverable; RAID-style risk register; decision
log with options and a vote date; retrospectives (keep / stop / start); a daily stand-up. Finance work follows the
office evidence standard (`keel/office/CHARTER.md` section 3): every number dated, with its basis, from code in the repo.

Keel's own story plan stays in `keel/road_to_semifinal.md` and `keel/tea_room.md` (fiction). Nothing here is copied
from Keel's fictional events into Caplet's deliverables.
