# keel/today/: what Keel did, one page per Sydney day

> Ray, 27 Oct 2026: "there's no some sort of like summary or like a list of things you guys done today ... make it
> clear essence ... very clear, simple, and update on the website constantly." The portal's front page (Today,
> https://raei-2748.github.io/caplet-investment/) is built from these files.

- `YYYY-MM-DD.md`: `## For Caplet` (at most four bullets, written by the Noticeboard at 07:00 and the Archive at
  19:10) and `## In plain words` (one bullet per finished room run, added by that room; runbook step 6). A huddle
  builder may add its own generated section under another heading; it never rewrites these two.
- The portal adds the rest on its own: conversations (members' labelled takes in the day's memos, meetings and
  `keel/huddles/`), research (the research rooms' memos and new research pages), Done (`pm/BOARD.md` Done rows,
  finished work orders, rooms' "Decided" lines) and the IPS rewrite's thinking log.
- A day with no file still shows, from the rooms' own `**Result.**` lines.
