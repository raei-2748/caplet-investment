the main session and the checkers compare each draft with this page and `SECTION_NOTES.md`.

arriving before the reader knew what it was: "the floor", "IBTM" and "its costs beyond its fee", "in 1 January 2033

uses to set it up again.

**How to check a draft against this page.**
1. Find each name's first use in the draft. It must be in the part named in column 3 or later, and the sentence that
   first uses it must say what column 4 asks, in plain words (round 11's third failure: names before things).
2. A table or figure counts as a use. If an exhibit uses a name before the prose has set it up, its title or note must
   set it up (judges look at exhibits beside the prose).
3. In 3a-3f, each name in column 6 marked "yes" is set up again in the short form given there, at its first use in the
   part, even if an earlier part set it up.
4. Column 7 is WORDS' "never" list for that name, plus the traps the notes add. Keel's working labels never reach prose.
