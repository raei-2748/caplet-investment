Read on Mon 23 Nov 2026 (Sydney). Every element was seen at a source on that day, not filled from memory or from
the cards:

- Journal articles: the Crossref record (api.crossref.org/works/DOI), which also carries any retraction, correction or
  "updated-by" notice.
- Where Crossref gives only a first page: the publisher's page (Oxford Academic), JSTOR, the Econometric Society or
  RePEc IDEAS.
- Books: the publisher's page, JSTOR and a university library catalogue.
- Works with no DOI: the issuer's own PDF or an archived copy of it (Internet Archive).

None of the 27 works has a retraction or correction notice in Crossref. Merton (1971) has a separate erratum, noted
in its row.

    49-55, not Spring 1994 as R02 and the plan say. The original's volume and pages (*Scientia, 98*, 108-113) are not
    printed on the reprint, so the entry cites the reprint that was read, with the original date.
  - Kocherlakota, Rosenbloom and Shiu (1988): REFERENCES_APA row 197 had ELEMENTS MISSING. The paper is now read in
    an archived copy of the SOA's own PDF, which confirms pp. 477-484. Volume 40 comes in parts, not issues, so the
    entry gives "(Pt. 1)", not "(1)". The journal's name is given as the article page prints it.
- **Resolved in passing.**

    note and Princeton's library catalogue), so "A. K." stands. The "Robert K." in Crossref and on the publisher's
    product line is an error in their metadata.
  - Leibowitz and Henriksson: card Q1c asked for the co-author's given name to be confirmed. Crossref gives "Roy D."
- **Form.** The four Financial Analysts Journal and JPM titles that print an em dash keep it here, as the source
  prints it (REFERENCES_APA rows 86-88 use a comma). Either form is acceptable, so these are not counted as fixes.
- **APA's rule that a cited work must have been read.** It is not met yet for four works, so read each before citing

  - Roy (1952): it is on a reading list only.
  - Black and Perold (1992): only the abstract was read.
  - McDonald and Siegel (1986): only the abstract of the published version was read. The working paper was read.

  Otherwise, cite the first three "as cited in" the work that was read.
