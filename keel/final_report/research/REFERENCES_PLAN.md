## 2. At risk of being lost: class-A works that were read but are not in `REFERENCES_APA.md`

This is the main list. Every work below was met in a card, a harvest or a reading file, and none has a row in
`REFERENCES_APA.md`. They are checked against the reference list by name, DOI and link. Each row gives the citation
elements that its source file gives, and these elements are not yet checked against the publisher. The "Read" column
says how deeply each work was read:

- **read**: the work itself was read, in full or in the part that was used.
- **card**: the work is in a card's source table, and the card records using it.
- **abstract**, **scanned**, **quoted**: only that much was seen.
- **reading list**: R02 records the reference but not always a full reading.
- **search result** or **index record**: only the listing was seen.
- **through quotation** or **as cited in**: the work was seen only inside another work.

APA says "cite only works that you have read". So before any work below is cited, it gets carded in the usual way
(publisher page, DOI, retraction check). Anything not read beyond a listing is read first. A work seen only inside
another is cited as "(Author, year, as cited in Other, year)", and only the source actually read goes in the list.

### 3c. What this means

1. A list of works read but not cited is not allowed. A separate bibliography or "further reading" page breaks APA,
   which Wharton requires (l.24, l.57). It would also count toward the 12 pages, because only References are outside
   the limit (l.67). A judge who knows APA would read it as padding.
2. A work stays in the list only if the report cites it somewhere, and a citation inside a table or exhibit counts.
   This is how to keep many works honestly.
3. Every cited work must have been read, and its idea must be in the report. A search result is not enough. Works seen
   inside another work are cited "as cited in".
4. Wharton bans links that evaluators are expected to open (l.59), so DOIs and URLs in the references should be plain
   text, not live links. The report should never ask the reader to open one.
