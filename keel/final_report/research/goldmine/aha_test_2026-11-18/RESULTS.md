## Limits of this test

- **One file per item worked as far as the answers show.** Every reference to another item in the three answer files
  points back to an item already read (for example Y on J, read eighth: "the earlier item's own condition"; N on R, read
  eighth: "while item L used world shares at 7.5%"). The release cannot be enforced, but unlike test 5 no flag cites a
  later item.
- **The order constraint shaped the control.** T came before W in every order, so W was never read first; X and Y name an
  earlier item for their lower surprise on W.
- **Recall was asked only at the end.** Here the key figure stayed in L, R and T whatever their position (R read seventh,
  third and eighth; L fourth, sixth and first; T second, first and fifth), so position does not explain the pattern.
- **Two of three roles are fixed-income specialists.** The scores are read by role, never pooled as one audience; the
  section above compares N with the two.
- **Simulated readers.** Recall after the filler task is only what each reports, never a measure of human memory
  (standing order 22).
- **Figures.** All from the register as re-sized Tue 17 Nov evening; 8u moves none. Today's engine's $65,000 (R) is Keel
  arithmetic written in 8s, not yet produced by `first_plan.py`.
