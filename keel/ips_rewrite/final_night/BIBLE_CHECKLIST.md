# Bible checklist: every expectation, as a test (V1 Bible Auditor, Thu 5 Nov 2026, Sydney)

Built from every word of `../../WHARTON_WORD.md`, `../../BIBLE.md` (cover note, Books 1-12, the Ten Commandments, the
"Standing" line, the overruled list) and `../../INSTRUCTIONS.md` I80-I88. Rank order: Wharton's word, then the books
(equal, Keel may weigh them if it says why), then I80-I88. Where two sources disagree, section C says which wins.
Each round's score (`rounds/RN_bible.md`) uses one row per line below: PASS / FAIL + quoted evidence from the draft.
**A FAIL on any line marked ★ sends the draft back to the drawing board** (Book 12: "if my exceedingly high
standards are not met, it's back to the drawing board").
